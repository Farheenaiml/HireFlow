# 3-minute demo script

**0:00 — the problem, in one line.**
"A recruiter reads 200 resumes for one role. The hard part is not reading them, it's being able to
say later *why* someone was shortlisted — and being able to prove it."

**0:15 — the principle.**
HireFlow never states a verdict without the quote behind it. Show the dashboard: evidence verified
percentage, items needing validation, decisions recorded by a human.

**0:35 — role setup.**
Paste the JD → requirements appear, split into must-have and nice-to-have. Edit one line, flip one
to nice-to-have. "The AI measures against my checklist, not its own idea of the job."

**1:00 — screening.**
Drop six resumes. Point out the redaction line: names, contact details, institutions are stripped
before the model sees anything. Hit Run screening, the board fills.

**1:25 — the board.**
Three columns with the rule printed above each one. "Strong is not a vibe, it's must-have coverage
above 0.75 with nothing missing. The maths is in the repo."

**1:40 — the money shot: evidence drawer.**
Open a candidate, click a requirement. Quote, reasoning, and the resume with the matched span
highlighted. Then open one that says *Unclear — evidence could not be located*: "the model tried to
cite something that wasn't there, the code caught it and downgraded the status automatically."

**2:05 — override.**
Change a status by hand. Score and group recompute instantly. "Humans overrule the AI, not the
other way around."

**2:15 — interview kit.**
Questions only for unresolved requirements, each with the gap it closes. Paste interview notes →
standardized report, unanswered areas flagged, rating and decision fields deliberately blank.

**2:40 — ask the pool.**
"Who still needs validation?" Answer comes back with [C2:R3] citations, each validated against the
database before display.

**2:50 — close.**
Audit trail: every insight, its source, its engine, its prompt version. "Hiring AI is
high-risk-by-regulation territory. HireFlow's answer is traceability, human decisions, and no
automated rejections."
